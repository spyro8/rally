## Approved direction

- Higher-detail handcrafted pixel art
- Contemporary athletic/outdoor apparel first
- Restrained light-fantasy accents
- Every accessory, companion, pose, animation, VFX element, and crest must match the same pixel language
- Classes are not gender-locked
- Personal wellness progress remains primary; the character system is a cosmetic reward layer
