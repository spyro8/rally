# 06 — Production Roadmap

## Phase 0 — Claude confirmation

Claude confirms:

- 1000×1400 character canvas
- 250×350 logical pixel grid at 4× scale
- y=1340 baseline
- file loading paths
- nearest-neighbor rendering
- overlay anchor behavior
- supported runtime formats

## Phase 1 — Pathfinder pilot

ChatGPT supplies:

- one base
- eight idle frames
- one level-up pose
- one boots overlay
- one fox profile companion
- contact sheet
- manifest update

Claude integrates and checks:

- stable identity
- stable baseline
- frame loop
- static fallback
- overlay alignment
- companion slot
- mobile performance
- reduced motion

Stop until accepted.

## Phase 2 — Remaining Pathfinder tiers

Complete all five Pathfinder tiers and validate evolution transitions.

## Phase 3 — Remaining flagship classes

Produce the five tiers for:

- Vanguard
- Sage
- Monk
- Guardian
- Tidecaller

## Phase 4 — Fixed class crests

Separate the approved six-crest board into six production masters and produce runtime sizes.

## Phase 5 — Team crest builder pack

Produce the first modular library:

- frames
- borders
- fields
- emblems
- accents
- palette tokens

## Phase 6 — Cosmetics and companions

Expand habit-linked equipment and companion libraries. Every item is class-compatible through configuration and visually matches the higher-detail pixel style.

## Phase 7 — VFX and celebrations

Produce isolated pixel VFX only after the base character and layer pipeline are stable.

## Phase 8 — Later systems

UI rewards and Castle War effect overlays are separate later approvals. Existing card-rarity frames, team crests already in production, and Rally’s crest-themed castles must not be replaced accidentally.
